# قطاعتي — صفحة هبوط مربوطة بمنصة صفقة

صفحة بيع لوح تقطيع ستانلس ستيل بالدفع عند الاستلام، مربوطة بمنصة **صفقة**
(Safka) عبر الـ Public API: المحافظات والمدن وأسعار الشحن بتيجي منهم، والطلب
بيتسجّل عندهم مباشرة أول ما العميل يضغط «تأكيد الطلب».

---

## 1) شغّل المشروع

```bash
npm install
```

```bash
cp .env.example .env
```

بعدين افتح `.env` وغيّر `ADMIN_TOKEN` لأي نص طويل وعشوائي (دي كلمة سر صفحة الإعداد).

**للتطوير:**

```bash
npm run dev
```

**للإنتاج:**

```bash
npm run build
```

```bash
npm start
```

الموقع بيشتغل على `http://localhost:3000`.

| المسار | الوظيفة |
| --- | --- |
| `/` | صفحة الهبوط + نموذج الطلب |
| `/checkout` | صفحة طلب مستقلة (مفيدة لروابط الإعلانات) |
| `/admin` | لوحة الإعداد والربط ومتابعة الطلبات |

---

## 2) ليه الربط لازم يمرّ من السيرفر؟

سببين، والاتنين مانعين أي حل من داخل المتصفح:

1. **المفتاح سرّي.** أي مفتاح تحطه في كود الواجهة يقدر أي حد يقراه من
   «View Source» ويستخدم حسابك. المفتاح هنا موجود على السيرفر بس.
2. **صفقة بترفض النطاقات الخارجية.** الـ API بتاعهم بيقبل CORS من نطاقات
   `safka-eg.com` فقط، وبيرد بخطأ 500 على أي Origin تاني — يعني نداء مباشر من
   المتصفح مش هينجح أصلًا.

عشان كده الترتيب كالتالي:

```
المتصفح  →  سيرفر قطاعتي (/api)  →  api.safka-eg.com
                     ↑ المفتاح محفوظ هنا
```

---

## 3) إزاي تجيب مفتاح الـ API (سؤالك في الاسكرين التالتة)

الخانات اللي في نافذة «إنشاء مفتاح» عند صفقة معناها كالتالي:

| الخانة | معناها | تحط فيها إيه |
| --- | --- | --- |
| **الاسم** | اسم توضيحي للمفتاح | `قطاعتي` |
| **هوك المنتج** (productHook) | لينك **بتاعك** صفقة تبعتله بيانات المنتج | `https://موقعك/api/hooks/product` |
| **هوك الطلبات** (orderHook) | لينك **بتاعك** صفقة تبعتله تحديثات حالة الطلب | `https://موقعك/api/hooks/order` |
| **Callback API** | لينك **بتاعك** صفقة تبعتله المفتاح نفسه مرة واحدة | `https://موقعك/api/safka/callback` |

> ⚠️ في الاسكرين اللي بعتّه كانت الخانات متملية بروابط `aff.safka-eg.com` —
> دي روابط منصة صفقة نفسها، مش روابط موقعك. لازم تحط روابط موقعك عشان صفقة
> تعرف توصلك بالتحديثات.

الروابط دي كلها **جاهزة ومكتوبة بالظبط** في صفحة `/admin` مع زرار نسخ لكل
واحدة، فمش محتاج تكتبها بإيدك.

### الطريقة السهلة (مُوصى بها)

بعد ما ترفع الموقع على دومين HTTPS:

1. افتح `https://موقعك/admin` واكتب الـ `ADMIN_TOKEN`.
2. اضغط **«اربط الموقع بحساب صفقة»** — هيوديك لصفحة الموافقة وكل الروابط متملية.
3. اضغط **«سماح»**.
4. صفقة هتبعت المفتاح لـ `/api/safka/callback`، والموقع هيحفظه لوحده في
   `.safka-key.json` ويشتغل فورًا من غير ما تعمل restart.

### الطريقة اليدوية

لو لسه شغّال محليًا (صفقة مش هتقدر توصل لـ `localhost`):

1. من لوحة صفقة: **التكاملات ← مفاتيح API ← إنشاء مفتاح**.
2. املأ الخانات بالقيم اللي في `/admin`.
3. انسخ المفتاح اللي هيظهرلك — **بيظهر مرة واحدة بس**.
4. حطه في `.env`:
   ```
   SAFKA_API_KEY=spk_xxxxxxxxxxxxxxxx
   ```
5. أعد تشغيل الموقع.

---

## 4) الطلب بيروح لصفقة إزاي؟

لما العميل يضغط «تأكيد الطلب»:

1. السيرفر بيتحقق من البيانات (الاسم، رقم مصري صحيح، العنوان، المحافظة).
2. **بيحسب الشحن من عنده** من `GET /api/v1/public/price-list` — مش من أي رقم
   جاي من المتصفح، عشان محدش يتلاعب بالسعر.
3. بيجيب المنتج من `GET /api/v1/public/product/:id` ويختار الـ property.
4. بيحسب العمولة = `(سعر بيعك − سعر المنتج على صفقة) × الكمية`.
5. بيبعت `POST /api/v1/public/orders` بالشكل ده:

```json
{
  "client_name": "محمود سيد",
  "client_phone1": "01098765432",
  "client_address": "المعادي، شارع 9 - مدينة نصر - القاهرة",
  "shipping_governorate": "معرّف المحافظة من price-list",
  "city": "336",
  "commission": 200,
  "total": "1240",
  "items": [{ "qty": "2", "product": "...", "property": "..." }],
  "page_name": "قطاعتي"
}
```

6. بيرجّع للعميل رقم الطلب (`serial_number`) من صفقة.
7. كل طلب بيتسجّل كمان في `orders.jsonl` عندك كنسخة احتياطية.

**لو صفقة وقعت أو المفتاح باظ**، الطلب **مش بيضيع** — بيتسجّل محليًا وبيظهر في
`/admin` بعلامة «محلي فقط» عشان تدخله بإيدك، والعميل بيشوف رسالة نجاح عادية.

---

## 5) تحديثات حالة الطلب

صفقة بتبعت على `orderHook` كل ما حالة الطلب تتغيّر (معلّق ← جار التحضير ←
في الشحن ← تم التوصيل…). الموقع بيستقبلها في `/api/hooks/order` وبيسجّلها في
`safka-events.jsonl`، وتقدر تشوفها من `/api/admin/events`.

---

## 6) تغيير السعر

من `.env`:

```
SELL_PRICE=590
COMPARE_AT_PRICE=700
```

بعدين أعد تشغيل الموقع. العمولة بتتحسب لوحدها من الفرق بين سعر بيعك وسعر
المنتج على صفقة — تقدر تشوف الرقم النهائي في `/admin`.

> راجع «أقل سعر بيع مسموح» في `/admin` قبل ما تنزّل السعر، عشان متبيعش تحت
> الحد اللي صفقة حاططاه.

## 9) النشر على Vercel

المشروع مجهّز لـ Vercel بالكامل: الواجهة بتتقدّم كملفات ثابتة، والـ API بيشتغل
كـ Serverless Function من `api/[...path].ts` (نفس كود `server/api.ts` بالظبط).

### إعدادات المشروع في Vercel

Vercel بيقرأ `vercel.json` تلقائيًا، فمش محتاج تغيّر حاجة في شاشة الإعداد:

| الإعداد | القيمة |
| --- | --- |
| Framework Preset | Other |
| Build Command | `npm run build:web` |
| Output Directory | `dist/public` |
| Install Command | `npm install` |

> ملف `.npmrc` موجود في الريبو وفيه `legacy-peer-deps=true`، فالتثبيت هينجح
> من غير ما تكتب أي flags.

### متغيّرات البيئة المطلوبة

من **Settings → Environment Variables** (لكل البيئات: Production / Preview / Development):

| المتغيّر | القيمة | إلزامي |
| --- | --- | --- |
| `ADMIN_TOKEN` | نص طويل عشوائي — كلمة سر `/admin` | ✅ |
| `SAFKA_PRODUCT_ID` | `6a7c9cab42d4b8fe405be078` | ✅ |
| `SELL_PRICE` | `590` | ✅ |
| `COMPARE_AT_PRICE` | `700` | ✅ |
| `PUBLIC_URL` | `https://دومينك` (من غير `/` في الآخر) | ✅ |
| `SAFKA_API_KEY` | مفتاح صفقة | ✅ (بعد الربط) |
| `SAFKA_PAGE_NAME` | `قطاعتي` | اختياري |
| `SAFKA_PROPERTY_ID` | سيبه فاضي | اختياري |
| `ORDERS_WEBHOOK_URL` | رابط نسخة احتياطية للطلبات | اختياري |

**لا تحط `PORT`** — Vercel بيتحكم فيه.

### مهم: التخزين على Vercel مؤقّت

نظام الملفات على Vercel للقراءة فقط، و`/tmp` بيتمسح مع كل نشر. يعني:

- **`.safka-key.json` مش بيفضل** → لازم تحط `SAFKA_API_KEY` كمتغيّر بيئة.
- **جدول «آخر الطلبات» في `/admin` هيكون فاضي** → مصدر الطلبات الحقيقي هو
  **لوحة صفقة**.
- كل طلب بيتطبع في **Vercel → Logs** (ابحث عن `[qataaty] ORDER`).
- لو عايز سجل دائم عندك، اضبط `ORDERS_WEBHOOK_URL` على Google Sheet
  (Apps Script Web App) أو Make/n8n وهتوصلك نسخة من كل طلب.

### ترتيب الربط بعد النشر

1. انشر الموقع وخد الدومين.
2. ضيف `PUBLIC_URL` و`ADMIN_TOKEN` والباقي، واعمل **Redeploy**.
3. افتح `https://دومينك/admin` واضغط **«اربط الموقع بحساب صفقة»** → **«سماح»**.
4. روح **Vercel → Logs**، هتلاقي سطر فيه `SAFKA_API_KEY=spk_...` — انسخ المفتاح.
5. حطه في Environment Variables باسم `SAFKA_API_KEY` واعمل **Redeploy**.
6. ارجع لـ `/admin` — لازم تلاقي **«الموقع مربوط بمنصة صفقة ✅»** واسم المنتج
   والعمولة وعدد المحافظات ظهروا.

> الخطوة 4 و5 ضرورية مرة واحدة بس، وسببها إن Vercel مش بيحفظ ملفات.
> بعد كده المفتاح ثابت في متغيّرات البيئة.

### الدومين

من **Settings → Domains** ضيف دومينك واتبع تعليمات الـ DNS. بعد ما يشتغل، غيّر
`PUBLIC_URL` للدومين الجديد واعمل **Redeploy** — عشان روابط الـ hooks اللي في
`/admin` تبقى صح.
